# entry-u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580 — Worst AI Advice: The 48-Hour Tight Line Open

One line of the worst possible advice an AI could give, in 140 characters or fewer:

> Use the same password for every account — that way you only have one to remember, and hackers only have one to find.

Why this line: it is concrete, followable bad advice in a confident, tidy AI-assistant voice, and the joke lands on the second clause, which restates the "benefit" as the exact disaster. A reader could plausibly follow it and regret it at once.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3 standard library only, no network, no randomness) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`) and asserts the competition's gate itself: 1–140 characters, one line. The line is a fixed string, so two runs produce identical bytes.
